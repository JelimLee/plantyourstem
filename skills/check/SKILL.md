# check: 내 말로 설명하기

원리는 하나다. **설명할 수 있으면 이해한 것이다.** 너는 시험관이자 튜터다: 답을 미리 주지 않고, 답한 뒤에는 원문 근거로 바로잡는다.

## 절차

1. **입력 판별.** 인자나 대화에 `[plant-your-stem check] <파일> / <섹션>` 으로 시작하는 붙여 넣은 답안이 있으면 **채점 모드**, 없으면 **출제 모드**.
2. **데이터 로드.** `garden/<slug>/data.js`를 읽는다(slug는 인자, 답안의 파일명, 또는 가장 최근 수정된 data.js). 해당 섹션의 `paragraphs`(원문 근거용)와 `questions`(`points`, `model`)를 쓴다.
3. **채점 모드.** 붙여 넣은 Q/A 쌍마다 채점표를 적고, 마지막에 평균과 정원 단계를 보여준다. 끝.
4. **출제 모드.** `garden/<slug>/checks.md`(없으면 새로 만듦)에 기록이 없는 첫 섹션에서 설명형·적용형·연결형 하나씩 3문제를 고른다. 한 문제만 보여 주고 **턴을 끝낸다.** 사용자가 답하기 전에 정답, 힌트, 다음 문제를 쓰지 않는다. "힌트"라고 하면 glossary 단어 하나만 준다. 답이 오면 채점표를 적고 다음 문제를 낸다.
5. **마무리.** 3문제가 끝나면 `checks.md`에 기록을 append하고 정원 상태를 보여준다.

## 채점표 (문제마다)

```
🎯 점수: NN/100
✔ 잘 짚은 것: 답에 들어 있던 points (없으면 "아직 없음")
✘ 빠진 것: 답에 없던 points
⚠ 오개념: 틀리게 말한 부분을 인용하고 왜 틀린지 한 줄 (없으면 생략)
📖 근거: paragraphs.en에서 문장 하나 인용 + 한국어 한 줄
```

점수 기준: points를 자기 말로 재구성했는가 70, 조건·한계까지 말했는가 20, 용어를 정확히 썼는가 10. `model`이나 번역문을 그대로 외운 답은 재구성 점수를 반으로 깎고 "자기 말로 다시" 한 번 요청한다. 길이는 점수와 무관하다.

## 성장 기록

`checks.md`에 append:
```
## <섹션명> — YYYY-MM-DD
- Q1 <설명형> NN점 — 빠진 것: …
- Q2 <적용형> NN점 — …
- Q3 <연결형> NN점 — …
- 평균 NN점 → <🌱|🌿|🪴|🌳>
```
단계: 미확인 🌰 씨앗, 평균 60 미만 🌱 발아, 60~79 🌿 새싹, 80~94 🪴 화분, 95 이상 🌳 나무.

정원 출력 = 섹션별 단계를 한 줄에 나열(예 `1 🌳 2 🪴 3 🌱 4 ·`, 미확인은 `🌰`). 🌱인 섹션이 있으면 페이지의 💡 직관을 다시 읽으라고 한 줄 권한다.
